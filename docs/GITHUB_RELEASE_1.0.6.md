ESP-INK 1.0.6 增加独立的拍立得/便签编辑流程，并修复删除其他图片时已下载预览被清空重读的问题。

- 点击A预览区先弹出底部类型选择窗：拍立得经系统相册进入C1，便签直接进入C2。C1保留全部照片工具，C2只显示便签底色和文字；编辑页不再切换类型。
- 完成回A后，调整按钮记住当前模式直达C1或C2，照片与便签文字分别保留；从隐藏照片文字切到便签时，已有便签文字正常显示。取消类型选择或相册选择不清空旧稿；迟到照片恢复不会覆盖刚选的便签。
- 确认删除图二后保留图一的PNG与高清缓存；删除前方图片时缓存按新编号移动。异常或外部变化继续核对身份，缩略图仍可空闲补高清。

351项统一测试及静态分析通过；Web实际验证类型弹窗、C1/C2与记住模式，Android Release实际构建、ZIP CRC和签名验证通过。图库缓存由协议/控制器回归验证，尚未在真实手机/ESP上验收。

电池卡片移除“上次有效读数，正在等待新采样”提示，保留最近有效电压及空闲读取逻辑，刷屏不会在APP中清空有效电压。

Android 7.0及以上，1.0.6+7，io.github.robbieht.espink，与ESP-INK 1.0.4/1.0.5包名和测试证书一致，可覆盖更新；仍为开发测试签名。附件提供APK、完整源码压缩包和SHA256SUMS，详细记录见docs/VERIFICATION.md。
