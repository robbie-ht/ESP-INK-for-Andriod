# 原控制页与Flutter功能对照

上游参考：[atunverse/moink](https://github.com/atunverse/moink)。

参考文件：同级 `moink-R1.3.4/page/index.html`。本次按其图片与文字创作能力实现Flutter编辑器，设备通信依据同级 `Moink-APP/docs/API.md` 的B2 BLE接口。该文件中部分注释使用比目录名更高的版本号，因此图像金标另记录实际源文件SHA256，不只依赖目录名。

## 图片与文字

| 原控制页功能 | 当前Flutter对应 | 范围与差异 |
|---|---|---|
| 拍立得、便签 | 创作页两种模式 | 首次拍立得为空白选图；便签不依赖照片。已移除旧海报模板。 |
| 浏览器选图、拖入、粘贴 | 系统相册选图 | Android使用系统照片选择器；未复刻浏览器拖入/剪贴板导入入口。 |
| 裁剪、居中、铺满、移动和缩放 | 铺满/完整显示、手势拖动/缩放及位置设置 | Flutter直接绘制照片，不依赖Cropper.js；裁剪边界按当前内容矩形。 |
| 90°与自由旋转 | 90°按钮、自由旋转滑块及双指旋转 | 图片镜像作为本地构图选项提供。 |
| 四边留白 | 留白开关、四边尺寸、恢复拍立得留白 | 横向逻辑画布；白边不进入图像滤镜。数值默认值不照搬竖向控制页。 |
| 自然暖调 `natural` | 自然暖调 | 颜色强度对应 `warmBoost`，保留冷色抑制与暖色拉回参数。 |
| 全面暖色 `adaptive` | 全面暖色 | 暖色浓度对应 `warmCast`，支持sunset/ember/duotone/sepia渐变。 |
| 灰度 `gray` | 灰度 | 先按亮度转灰，再按所选色域进行四色量化；不承诺强制纯黑白。 |
| 原色直出 `naive` | 原色直出 | 跳过色相风格映射，仍可应用亮度/对比度/伽马、色阶、锐化和抖动。 |
| 8种抖动 | FS、Stucki、Jarvis、Burkes、Sierra Lite、Atkinson、Bayer 8×8、无 | `sierra` 保持原页面的Sierra Lite核；支持抖动强度。误差扩散采用蛇形扫描。 |
| 标准/线性光/sRGB | 3种色域 | 标准保留γ=1.75以及校准红/黄目标色；最终输出仍是四色设备码。 |
| 高级参数 | 图像调整及暖色精细调节 | 亮度、对比度、伽马、饱和度、自动色阶、锐化、暖色中心/跨度、冷色偏移/角度上限/去饱和、暖色拉回/角度上限。 |
| 多文字对象、添加/编辑/删除 | 拍立得与便签各自的文字列表 | 两种模式文字独立；文字可单独开关。 |
| 字体 | 黑体、宋体、等宽 | 实际打包Noto Sans SC、Noto Serif SC、Noto Sans Mono SC；原页系统字体中的楷体未提供。 |
| 字号、文字拖动与旋转、宽度 | 字号/位置/方向/换行宽度设置，画布手势 | 保留相应编辑能力，不复刻原页四角DOM控制柄；提供加粗。 |
| 文字色、描边、对象底色 | 四色文字和描边、透明或四色文字底色 | 黑白黄红严格使用设备调色板。 |
| 便签屏幕底色 | 黑、白、黄、红底色 | 便签不做图像风格化与抖动。 |
| 图像先处理、文字后叠加 | 相同处理顺序 | 照片内容区先量化，再叠文字并吸附四色，避免扩散误差污染文字边缘。 |
| 竖向552×768编辑与预览 | 正向横屏768×552编辑与预览 | 不自动导入旧页面文字/留白坐标；传输只使用B2既有180°打包契约，不叠加原页90°转换。 |
| 页面本地状态 | 本地 `composer.v2` 草稿 | Flutter保留文字、布局和处理参数；照片字节不持久化。没有导入旧网页localStorage的迁移器。 |

`test/image_filter_vectors.json` 包含112组原JS执行结果：96组覆盖4风格×8抖动×3色域，另16组覆盖四种风格、四套渐变及高级参数。Dart核心逐像素比对这些结果。渲染测试另核对白边隔离、文字后叠加、预览与帧一致性。该兼容范围是相同RGB输入的处理算法；照片解码、字体度量、横竖编辑几何和实体面板显示仍需各自验收。

## 从Wi-Fi控制页到BLE应用

| 原控制页功能或接口 | 当前Flutter对应 | 边界 |
|---|---|---|
| 连接热点、打开192.168.4.1、HTTP `/api/*` | Android BLE服务UUID扫描、连接、握手 | 无Wi-Fi配网、HTTP地址或系统蓝牙配对步骤；设备应运行B2固件。 |
| 上传并刷新屏幕 | 立即显示 | 不追加图库；缓存行为遵循B2设置和发送标志。 |
| 上传到图库 | 仅存入图库；另提供存入图库并显示 | 保存和刷屏分别等待STORE_DONE与DISPLAY_DONE，不以上传100%当成功。 |
| 设备轮播图库、缩略图、大图、删除/清空 | 设备图库分页、带revision回读、缩略图/完整帧预览、显示/下一张、删除/清空 | 容量由设备报告，当前目标8项；STALE丢弃部分下载，追加不自动覆盖。 |
| 版本、屏型、电池和状态 | 设备页版本/状态/电压/实际MTU等 | 数据以B2返回字段为准，不合成热点在线数等Wi-Fi指标。 |
| 超时、休眠/关机、定时唤醒、唤醒切图 | B2设置读写及回读 | 深睡不能由手机BLE远程唤醒；自锁关机依赖GPIO2与实际电路。 |
| 热点名、密码、Wi-Fi功率 | 无对应热点设置 | B2提供的是最长20个UTF-8字节的BLE名称；不是SSID或Wi-Fi认证信息。 |
| A0/A1屏型 | 屏型设置 | 与GPIO预设独立。 |
| 固件全局 `hflip` | 不提供该设备设置 | B2未暴露该字段；拍立得镜像仅影响当前图像，不改变设备所有输出。 |
| GPIO预设/自定义 | 同样的0/1/2/3编号及自定义校验 | 当前固件出厂为2整合板；旧有效NVS保留。变更需重启并回读，GPIO2固定自锁。 |
| `.bin`与`.html`升级、恢复内置网页 | BLE应用bin OTA | 仅适用ESP32-C3/B2应用镜像；不接收HTML、bootloader或合并全量固件，不更新网页。首次分区迁移走USB。 |
| 清理残影、恢复出厂 | B2对应命令 | 完成依据设备事件和重连状态，不能沿用旧页固定耗时提示。另提供缓存重刷、重启、主动深睡。 |
| 下载离线HTML客户端 | Android安装包；浏览器本地预览/演示 | 浏览器版本不提供真实BLE控制；本地演示明确标记且不发送设备命令。 |

实现与硬件验证分开记录：构建、静态分析、自动化测试与截图见 [VERIFICATION.md](VERIFICATION.md)；未完成的实体设备操作见 [hardware-check.md](hardware-check.md)。
