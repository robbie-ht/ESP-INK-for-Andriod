主页A只保留一处照片选择／结果预览及“调整图片”“发送图片”。点击预览区直接打开系统相册B，选图成功自动进入调整页C；取消选择或读取失败保留原照片与参数，不进入C。

C默认查看墨水屏效果并自动更新，竖屏固定上方预览、下方滚动参数，横屏左右分栏；原图、裁切旋转、文字、留白和完整滤镜均在C中，便签入口也在C。点“完成”或系统返回保留编辑并回到A，生成最后一次效果，再发送；“调整图片”直接重进C。从C更换照片时继续使用当前C，等待系统选图期间暂时锁定退出；Android丢失选图恢复成功后只自动进入一次C。裁切子页仍是“应用”提交、“取消”不改草稿。

图库先读缩略图，再在空闲时补读高清；确认追加成功会保留已有高清预览。电压偶发无效时保留并标注最近有效读数，不冒充当前新采样。

本版源码版本为1.0.5+6，应用ID沿用ESP-INK 1.0.4的 `io.github.robbieht.espink`，相同签名可覆盖更新并保留草稿。只有从旧MoInk 1.0.3及更早版本迁入时，才因包ID不同而独立安装、无自动草稿迁移；旧MoInk和旧相册文件继续保留。相册保存目录为 `Pictures/ESP-INK`。Docker缓存位置可通过 `ESP_INK_CACHE_DIR` 指定。

本版测试、静态检查、Web界面及Android Release编译、完整性/验签结果见[验证记录](VERIFICATION.md)。交付包使用测试签名；旧APK和源码归档保留。实体手机BLE、实际采样与相册保存仍需实测。详细日志、校验值及界面截图见验证记录。
