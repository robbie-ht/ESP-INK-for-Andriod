# ESP-INK 1.0.4 安卓APP

源码、实际编译目录、APK和文档集中于 `/home/descfly/桌面/ESP32/APP/`，不使用软链接。

- 新安装包：[ESP-INK-1.0.4-android.apk](../releases/ESP-INK-1.0.4-android.apk)。
- 最新源码包：[ESP-INK-Flutter-source.tar.gz](../releases/ESP-INK-Flutter-source.tar.gz)。
- [GitHub Release v1.0.4](https://github.com/robbie-ht/ESP-INK-for-Andriod/releases/tag/v1.0.4)。
- Docker构建入口：tool/build_android.sh；实际产物：build/app/outputs/flutter-apk/app-release.apk。
- [验证记录](VERIFICATION.md)、[真机步骤](hardware-check.md)、[1.0.2恢复说明](RECOVERY-2026-11-21.md)。

选择“墨水屏效果”后自动生成与更新，点“边看效果边调整”进入固定预览的调整页；竖屏上下分区，横屏左右分栏。图库先读缩略图，再在空闲时补读高清；确认追加成功会保留已有高清预览。电压偶发无效时保留并标注最近有效读数，不冒充当前新采样。

本版源码版本为1.0.4+5，应用ID为 `io.github.robbieht.espink`。包ID改变后是独立安装，可与旧版并存；不会删除旧版，也不会自动迁移旧版草稿。相册保存目录为 `Pictures/ESP-INK`。Docker缓存位置可通过 `ESP_INK_CACHE_DIR` 指定。

本版测试、静态检查、Web界面及Android Release编译、完整性/验签结果见[验证记录](VERIFICATION.md)。交付包使用测试签名；旧APK和源码归档保留。实体手机BLE、实际采样与相册保存仍需实测。详细日志、校验值及界面截图见验证记录。
